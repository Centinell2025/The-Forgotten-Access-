# Simulation and use constraints

All records, usernames, domain names, paths, employers and employees in this package are fictional. Northbridge Systems Ltd. is not a real case victim. Beacon of the Eagle LLC / Centinell Suite Defense is the content publisher, **not** the simulated victim. No IP addresses, passwords, malware, real PII or third-party corporate network traffic are included.

The exercise supports defensive incident response and audit training only. It is designed for offline analysis on Kali Linux, Ubuntu, macOS or Windows. No exploitation, credential guessing, malware execution, or external network contact is required.

**Integrity:** use `tools/checksums.py` to generate SHA-256 values for the local evidence files. Because these are synthetic exhibits, hashes attest to distributed exercise bytes, *not* independent forensic acquisition from a genuine victim host.

Public materials must not contain the private instructor answer key or the ten literal answers. Main graded questions: 10. Optional practice exercises: 10 x 3 questions, ungraded.
